# 관리청 단말기 사진

RisuAI 봇 「마법소녀는 아무것도 느끼지 못 한다」의 관리청 단말기 플러그인이 불러오는 사진이다.

- `hq/` 관리청 본부 층별·외관 사진
- `map/` 지도 장소 사진 (출처는 CREDITS.md)
- `thumb/` 인물 얼굴 384px
- `profile/` 인물 프로필 원본(세로)

플러그인은 jsDelivr 태그 주소로 읽는다: `https://cdn.jsdelivr.net/gh/candycookiechocoretto/Img@v1/thumb/hina.webp`
사진을 바꾸면 새 태그(v2…)를 만들고 플러그인의 태그를 올린다.
